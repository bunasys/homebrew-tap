# Buna Systems Homebrew tap

```sh
brew install bunasys/tap/nawa
```

| Formula | What it is |
| --- | --- |
| `nawa` | [Nawa](https://github.com/bunasys/nawa), a small agent harness in Swift (macOS on Apple Silicon, Linux x86-64) |

`Formula/nawa.rb` is written by Nawa's release workflow
(`scripts/homebrew-formula.sh` in that repo): don't edit it by hand.
